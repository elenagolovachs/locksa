PhoneLocker — исходный Android-проект

Важно:
- Это исходный проект, не готовый APK.
- Для сборки нужен Android Studio с Android SDK и Gradle.
- В приложении вручную укажи package name целевого приложения.
- Разреши «Отображение поверх других приложений» и «Доступ к статистике использования».
- После включения сервис показывает PIN-экран поверх выбранного приложения.

Ограничения:
- Это базовая демонстрационная реализация, не замена системной блокировке Android.
- Некоторые версии Android и оболочки производителей могут ограничивать фоновые сервисы и показ окон.
- Не используй её как защиту критически важных данных.
